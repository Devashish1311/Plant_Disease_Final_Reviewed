ES 335 · UNDERGRADUATE MACHINE LEARNING PROJECT

Can handcrafted image features identify potato leaf diseases?

A comparative study of colour and texture descriptors for distinguishing healthy leaves, early blight and late blight using traditional machine learning.

01 · PROBLEM FORMULATION

Which visual features carry the most useful information?

We ask whether colour statistics, GLCM texture, Local Binary Patterns (LBP), or their combination best distinguish three labelled potato-leaf categories.

Scope of the claim

This is a three-class image-classification experiment on the PlantVillage potato subset. It is not a field-tested diagnostic tool and does not locate individual lesions.

03 · PREPROCESSING

From image files to comparable inputs

01

Find and validate images

Search the three potato class folders recursively; skip unreadable images.

02

Remove exact duplicates

Compute SHA-1 hashes and retain one copy of byte-identical image files. This does not detect every visually similar image.

03

Standardise image size

Convert to RGB and resize each image to 128 × 128 pixels.

04

Create feature representations

Use HSV for colour descriptors and grayscale images for GLCM and LBP texture descriptors.

04 · FEATURES AND METHODS

Four representations, three learned classifiers

54 dimensions

Colour · HSV

For each H, S and V channel: mean, standard deviation and a 16-bin histogram. These summarise the image's colour distribution.

48 dimensions

Texture · GLCM

Six properties (contrast, dissimilarity, homogeneity, energy, correlation and ASM), across two distances and four angles.

10 dimensions

Texture · LBP

Uniform Local Binary Pattern histogram with eight neighbours and radius one.

112 dimensions

Combined

Concatenation of the 54 colour, 48 GLCM and 10 LBP features.

Models compared

Majority-class baselineLogistic RegressionRBF Support Vector MachineRandom Forest

Logistic Regression and SVM use standardisation inside a scikit-learn pipeline. Hyperparameters are selected by stratified 5-fold cross-validation on the training set only. Random Forest uses class weighting and does not require feature scaling.

05 · EVALUATION DESIGN

Keep model selection separate from final testing

Data split

80% training and 20% held-out testing, using stratification to preserve class proportions.

Model selection

Stratified 5-fold cross-validation and grid search are performed on the training portion.

Metrics

Accuracy, macro-F1, macro precision and macro recall. Macro-F1 gives each class equal weight.

All test metrics below are computed once on the held-out 431-image test set. The final test set is not used for hyperparameter selection.

Interpretation

Colour features alone are strong in this experiment. GLCM and LBP alone perform less well, while the combined representation gives the highest macro-F1 with Random Forest. The combined SVM has the highest accuracy. This shows why the choice of metric matters: the model with the highest accuracy is not necessarily the model with the highest macro-F1.

07 · LIMITATIONS

What these results do not establish

  • Class imbalance: only 152 healthy images are available, compared with 1,000 in each disease class. The held-out test set contains only 31 healthy images.
  • Controlled image conditions: PlantVillage images do not represent the full variation of farm photographs, lighting, backgrounds and camera conditions.
  • Duplicate handling: exact byte-identical files are removed; near-duplicates may remain.
  • Feature scope: global image descriptors are used. The project does not segment or localise individual lesions.
  • External validity: no independent field dataset was used, so real-world generalisation is not demonstrated.
Careful conclusion

On this PlantVillage potato subset and this particular split, handcrafted colour and texture features combined with traditional classifiers achieved high test scores. Further evaluation on balanced and independently collected field images is needed before making practical diagnostic claims.
